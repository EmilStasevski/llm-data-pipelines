# ADR 0008: Synthetic data generator and evaluation sets (Phase 3)

- Status: accepted (Phase 3, 2026-11-07).
- Context: PLAN §6 asks for deterministic German NRW data with gold labels at S/M/L/XL, questions and qrels. Several details were open or had to deviate.
- Decisions:
  - **Labels → text, prefix-stable.** Rows are generated in fixed 10 000-row chunks seeded by `SeedSequence(seed, spawn_key=(table, chunk))`; each chunk draws one uniform matrix with one column per decision (`IntEnum`), so row i depends only on (seed, i). S ⊂ M ⊂ L ⊂ XL byte-identically (verified on the real files, also across refactors). Questions built on small row ranges stay valid; chunks run in parallel worker processes (`spawn`, not `fork`: pyarrow threads).
  - **Visible formats match Track A's parse rules**, and a test-only reference parser recovers *every* gold value of 10 000 rows (mutation-checked). Additions to PLAN §7.2: date variant `D.M.YY`; thousands separator **NBSP instead of thin space** (U+2009 is not cp1252-encodable); one-sided Q tolerances as `max.`/`<=`/`min.` (`≤` not in cp1252).
  - **Exports:** cp1252 CSV with CRLF (Windows/SAP export), UTF-8 CSV with LF, Parquet (zstd) with identical visible content, gold Parquet with typed columns. The cp1252 writer is strict: it caught `"µ".upper()` → Greek `Μ` (U+039C), now handled by a µ-preserving upper case.
  - **Mojibake** only for the eight characters of the fixed repair table (`text.encode("utf-8").decode("cp1252")`), so the Track A repair is an exact inverse. Noise is applied only to free text, with tags recorded in gold (`noise`).
  - **Quality notifications** at 0.1 × scale rows; verdict i.O. ⇔ class "kein Fehler"; values keep ≥ 1 rounding unit from tolerance limits (rounding can never flip a verdict); fail-loud assertion at generation time.
  - **Track C relevance is a rule, not a list** (`zj_eval.relevance.grade`: 2 = component + damage type, 1 = one of them / same equipment group, 0 otherwise; outside the metadata filter always 0). The qrels file stores the definition and grade counts; the SQL used for the counts is tested equal to the Python rule. Filter classes are calibrated to PLAN §9 (measured at M: werk 3.7 %, date 14 %, combined 1.3 %).
  - **Track E** questions per scale (M, L): lookups only on keys unique at that scale; filtered semantic questions with 3–150 gold IDs (extra narrow filters werk+quarter/half-year so L keeps variety); aggregations carry their gold SQL.
  - **Real data:** values are kept verbatim (thru.de terms forbid altering), no noise. Data minimisation: no PRTR facility names/streets, TED contact data redacted (CC BY: change marked in the card), BA search results only, company names without a legal form set to null.
- Consequences: generated files are reproducible from `task data:all` (offline); dataset cards are regenerated from manifests and the data (`task data:cards`). `config/datagen.yaml` `chunk_rows` must never change casually, because changing it changes every row.
